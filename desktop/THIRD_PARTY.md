# Assets and dependencies

The air-conditioner illustration is copied from the macOS app. Its original generation prompt accompanies it in `assets/air-conditioner.prompt.txt`. The app icon is converted from the existing HomeControl ICNS.

Interface icons are simple authored SVG line geometry. Dependencies and their licenses ship with Electron/electron-builder's generated third-party notices and the installed npm packages. The runtime application uses Electron and ws; electron-builder is a build dependency.
